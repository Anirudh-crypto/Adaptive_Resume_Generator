% Static document used only to pre-warm Tectonic's package bundle cache during the Docker build.
%
% It deliberately mirrors the preamble of resume.tex.jinja so that every package the real
% pipeline needs is already in the image's cache at runtime -- production compiles then need no
% network access, and cold starts aren't paying for a package download.
%
% Keep this preamble in sync with resume.tex.jinja. If a package is added there but not here,
% the first real compile in production pays a download (and fails outright if egress is blocked).
%
% This file is static on purpose: the Dockerfile compiles it *before* copying app/, so an
% ordinary code change cannot invalidate the ~100MB bundle layer and force it to be rebuilt and
% re-pushed to Artifact Registry.
